# MCU Complete — GitHub Pages static addon

Upload the files/folders in this package to the root of a GitHub Pages repository.

The manifest and catalog JSON files are static. This package contains metadata/catalog information only and no streaming links.

After GitHub Pages is enabled, the manifest will be at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/manifest.json`

If Stremio rejects the mixed catalog, use the TV fallback catalog separately; Stremio's catalog schema normally expects catalogs to be typed as movie or series.
